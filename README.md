# Defrag

Defrag is a touch-friendly puzzle game about consolidating fragmented files. The campaign includes 30 puzzles on a four-row, six-column board.

Serve the repository root with any static web server. For example, run `python3 -m http.server 8000` and open `http://localhost:8000`.

Tap a block to select a run, then tap a highlighted destination. Tap within a selected run to split off a block or choose a range. Striped sectors are reserved, and corner labels mark each file's home.
