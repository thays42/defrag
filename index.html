How to play

Move a run
Tap a block to select its whole run, then tap a coral destination. Runs can wrap across rows.
Split a run
Tap inside a selected run to pick one block. Tap another block in the run to select the range between them, or tap the marked block again to return to the whole run.
Clear the board
Join each file into one run. If it has a home, finish the entire run in sectors with the matching corner label. You can use any empty sector as workspace. Solid gray sectors are reserved.
Meet par
Each move costs 1 point, and splitting adds 1 extra point. Lower scores are better.
