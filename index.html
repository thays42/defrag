    How to play

    Move a run
    Select a block to pick up its whole run. Coral sectors are destinations: select one to move the run there. An arrow (← →) marks a nudge. With a mouse or keyboard, hover or focus one first to preview where it lands. Runs can wrap across rows. Select empty space to cancel.
    Split a run
    Select a block inside the picked-up run to take just that block. Select another block in the run to take the range between them, or the marked block again to take the whole run.
    Clear the board
    Join each file into one run. If it has a home, finish the entire run in sectors with the matching corner label. A file shows ✓ once it meets all its own rules. Hatched sectors are reserved.
    Meet par
    Each move costs 1 point, and splitting adds 1 extra point. Lower scores are better. One ★ for a clear, two without hints, three without hints at par.
    Badges
    Some levels offer badges for a different goal that costs more than par. ▭ Tidy: free space in one stretch. ▮ Unsplit: no splits. ↝ Light touch: low total travel. ⁂ Few moves: few moves on a seek level. ✦ Under par: beat par. Each has its own target score. Hints void badges.
